# Repository guidance

- Use Node.js 24. Run `npm run check`, `npm test` and `npm run build` before handing off changes.
- Keep pages statically generated. Use server-rendered Astro components and scope client JavaScript to the interaction.
- Translate interface changes in English and Brazilian Portuguese. Build route and public asset URLs using the helpers in `src/lib/site.ts`.
- Keep editorial entries in Git and drafts private. Publish only approved writing and recommendations.
- Keep illustrative financial scenarios clearly labeled. Intelligence requires verifiable source metadata.
- Document changes to the publishing workflow or design system in the appropriate guide.
